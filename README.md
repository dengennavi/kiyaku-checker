# 規約チェッカー

利用規約の文章を貼るだけで、気になる条項を色分けして表示する無料ツールです。

**👉 https://dengennavi.github.io/kiyaku-checker/**

- 🔴 要確認：同意前に必ず読みたい条項
- 🟡 確認推奨：読んでから判断したい条項
- 🟢 該当なし：30項目のルールに当たらない条項

## 使い方
- **Web**：上のページに規約を貼って「判定する」
- **LINE**：[@823qtyqg](https://line.me/R/ti/p/@823qtyqg) を友だち追加して、トークに規約を貼って送る（「デモ」で試せます）
- **X**：[@kiyaku_checker](https://x.com/kiyaku_checker)（お問い合わせはDMへ）
- **作った話**：[Zennの記事](https://zenn.dev/kiyaku_checke/articles/2d45887a2b6c54)（技術向け）／[noteの記事](https://note.com/kiyaku_checker/n/n982fe5b09ddd)（予算1万円・AIなしで作った理由）
- [利用規約・プライバシーポリシー](https://dengennavi.github.io/kiyaku-checker/legal.html)（規約チェッカー自身で🔴0件・🟡0件）

## 特徴
- **貼った規約はサーバーに送りません。** 判定はすべてブラウザの中で行います
- **判定ルール30項目を公開しています**（`rules.js`）。消費者契約法・民法548条の2（定型約款）・個人情報保護法などをもとにしています
- 指摘には、反応した文・理由・根拠の法律を必ず表示します
- AIは使っていません。ルール（正規表現）との一致を機械的に表示するツールです

## ご注意
本ツールは一般的な情報提供を目的としたもので、法的助言ではありません。個別の契約について法律上の有効・無効を判断するものではなく、表示されない条項にも問題がある可能性があります。重要な契約は弁護士等の専門家、または消費生活センター（188）にご相談ください。
