# X（@kiyaku_checker）にログインするやり方

**Googleのボタンは使わない。規約チェッカーはGoogleでは入れない。**

## ログアウトしていたとき（2026-11-24 にこれで入れた）
1. いつものChromeで x.com を開く（ネゴカーなどほかのアカウントで入っていればそのままでよい）
2. 左下のアカウント名の横の「…」→「既存のアカウントを追加」
3. Googleの小さい画面が勝手に出たら、右上の × で閉じる
4. X の枠の下の白い入力欄（「メールアドレスまたは…」）を1回押す
5. Chromeが覚えている一覧が出る → 上から5番目くらいの「kiyaku_checker」を押す
6. 「続ける」→ パスワードは自動で入る →「ログイン」
7. 左下が「チェッカー @kiyaku_checker」になっていれば完了

## 投稿するとき
- 左下が @kiyaku_checker か確かめる（ネゴカーになっていることがある）
- 左の「投稿」→ Ctrl+V →「ポストする」（文はClaudeがクリップボードに入れる）
