## きっかけ：「猫をください」に気づけるか

ある動画で、フリーWi-Fiの利用規約の途中に「飼育中の猫を無償で譲渡する」という一文を紛れ込ませる実験がありました。ほとんどの人が気づかずに「同意する」を押します。

規約を全部読むのは現実的ではありません。それなら、**気になる条項だけ光らせる**道具があればいい、というのが出発点です。

デモ用の架空の規約（「にゃんネット」Wi-Fi利用規約）を貼ると、こうなります。

```
🔴要確認 2件／🟡確認推奨 6件／🟢該当なし 4条

🔴 第7条（対価）
「利用者は、本サービスの利用の対価として、飼育中の猫を当社に無償で譲渡するものとします。」
→ あなたの財産をタダで差し出す内容です

🔴 第8条（免責）
「当社は、本サービスに関して利用者に生じたいかなる損害についても、一切の責任を負いません。」
→ 問題が起きても一切賠償しない、という内容です
```

## 設計で決めたこと

### 1. 規約はサーバーに送らない

判定は**すべてブラウザの中**で行います。貼った規約は1文字も外に出ません。サーバー代も0円で、GitHub Pagesに置いているだけです。

### 2. AIを使わず、公開ルールで判定する

判定は、消費者契約法・民法548条の2（定型約款）・個人情報保護法などをもとにした**30項目のルール（正規表現）**で行います。ルールは全部公開しています。

AIを使わなかった理由は、次の2つです。

- **理由を必ず示せる**：どの文のどの言葉に反応したか、根拠の条文は何かを、毎回表示できる
- **「判断」ではなく「一致の表示」にとどめる**：法務省のガイドライン（2023年）では、あらかじめ用意したチェックリストとの一致を機械的に表示する機能は、通常は弁護士法72条の「法律事務」に当たらない例とされています。そこで表示も「危険／安全」ではなく、**「要確認／確認推奨／該当なし」**にしました

ルールはこんな形です。

```js
{ id: "EXC-01", cat: "免責", sev: "danger",
  title: "損害賠償責任の全部免除",
  plain: "問題が起きても一切賠償しない、という内容です",
  patterns: [/一切の?(?:責任|賠償責任|損害賠償)を?(?:負|お)(?:いません|わない|いかね|わず)/],
  law: "消費者契約法8条1項1号" }
```

### 3. 条項ごとに分けて、文ごとに当てる

`第◯条` で条項に分け、さらに「。」で文に分けてから照合します。`第◯条` がない規約は「1. 定義」のような番号の見出し、それもなければ空行で分けます。

## 実在の規約9本で試したら、8割が誤りだった

ルールを30項目そろえたところで、国内外の大手Webサービス9本の公開規約で試しました（社名は伏せます）。

結果、🔴が **17件** 出ました。ところが中身を読むと、**14件は誤り**でした。

### 誤り①：別の条に「例外」が書いてある

いちばん多かったのが「当社は一切の責任を負いません」です。条項単体で見ると、消費者契約法8条が無効とする「全部免除」に見えます。

ところが **9本中5本** は、規約の別の条でこう定めていました。

> 当社の故意または重過失による場合は、この限りではありません。
> 消費者契約法の消費者契約に該当する場合、当社の損害賠償責任を完全に免責する規定は適用されません。

これがあると、規約全体としては「全部免除」ではありません。**規約は1つの条ではなく、全体で読む必要がある**、という当たり前のことを、ツールにも教える必要がありました。

そこで、ルールに「文書全体で探す例外」を持たせました。

```js
// 規約全体のどこかに「故意・重過失は除く」等があれば、🔴を🟡に下げて条番号を示す
const docSave = {};
for (const rule of rules) {
  if (!rule.docMitigate) continue;
  const c = clauses.find(c => rule.docMitigate.test(c.body));
  if (c) docSave[rule.id] = c.label;
}
```

結果画面には「この規約は第◯条で例外を定めているため、全部免除にはあたらない可能性があります」と、どの条かまで表示します。

### 誤り②：第三者や利用者自身が原因の免責

「第三者による不正利用について、当社は一切の責任を負いません」「利用者間のトラブルについて、当社は一切の責任を負いません」。

これらは事業者自身の落ち度の免除ではないので、🟡に下げることにしました。

### 誤り③：主語が違う

「当社サービスに関する著作権は、当社に帰属します」に、「投稿の権利を事業者に譲渡」のルールが反応していました。これは事業者自身の著作物の話です。主語が「ユーザー・投稿」のときだけ反応するように直しました。

### 結果

🔴は **17件 → 3件** になりました。残った3件は、どれも「例外の定めがどこにもない、一切責任を負わない条項」です。

この誤りの数々は、すべて回帰テストにしています。

```js
const r = A("第1条（ID）\n第三者による不正利用について当社は一切の責任を負わないものとします。");
expect(!has(r, "EXC-01", "danger"), "第三者による損害の免責 → 注意");
```

**「🔴を出しすぎるツールは、誰にも信用されない」**。今回いちばん学んだことです。

## LINE版：Cloudflare Workersで無料運用

LINEでも使えるようにしました。仕組みは単純で、LINEから届いた文章を、Webと**同じ判定エンジン・同じルール**で判定して返信するだけです。

- 置き場所は Cloudflare Workers（無料枠）
- 送られた文章は保存しない
- LINEの長期アクセストークンは置かず、チャネルIDとシークレットから15分有効のトークンをその都度発行

```js
async function getToken(env) {
  const res = await fetch("https://api.line.me/oauth2/v3/token", {
    method: "POST",
    headers: { "Content-Type": "application/x-www-form-urlencoded" },
    body: new URLSearchParams({ grant_type: "client_credentials",
      client_id: env.LINE_CHANNEL_ID, client_secret: env.LINE_CHANNEL_SECRET })
  });
  return (await res.json()).access_token;
}
```

## 自分の規約も、自分のツールで通した

規約をチェックするサービスに規約がないのはまずいので、利用規約とプライバシーポリシーも書きました。

書くときは、自分のツールが指摘する書き方を避けました。

- 「一切責任を負いません」→「故意・重大な過失がある場合を除き」
- 「その他、当方が不適切と判断した行為」→ 禁止事項は具体的に4つだけ
- 「予告なく変更」→「7日前までにお知らせ」

結果は **🔴0件・🟡0件** です。
