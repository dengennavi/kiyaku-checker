# X：困っている人への返信（2026-11-15〜）

毎日の投稿はやめた（フォロワー0で届かないため）。かわりに、困っている人の投稿に返信する。

## やり方（1日2〜3件まで）
1. X の検索欄に下の「検索する言葉」を入れて、「最新」タブを見る
2. 返信したい投稿のスクショを Claude に見せる
3. Claude が返信の文を作ってクリップボードに入れる → 貼って送る
4. リンクの末尾の ?x= の印は、カード画像を変えたら新しくする（X が古い画像を覚えているため）

## 返信のルール
- 返信の文そのもので答えを書く。リンクは最後に補足として付けるだけ（リンクだけの返信は連発しない）
- 1日2〜3件まで。同じ文を何人にも送らない（スパム扱いされるため）
- 「違法」「詐欺」と決めつけない。規約の条文と公式の案内の事実だけ
- 個人の契約の判断はしない（法的助言ではない）。困りごとが大きそうなら消費生活センター（188）を案内
- 予算・登録数など内部の事情は書かない
