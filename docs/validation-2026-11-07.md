# 実在規約での精度検証（2026-11-07・辞書 v1.0 → v1.2）

対象：公開されている利用規約 9本（国内外の大手Webサービス。社名は非公開）
※取得できなかったもの：5社（JavaScriptで描画するページ等）。v2のURL判定でも同じ壁があるため要検討。

## 結果
| 指標 | v1.0 | v1.2 |
|---|---|---|
| 🔴危険の件数（9本合計） | 17 | **3** |
| 🔴のうち誤り（例外規定の見落とし・別物の条項） | 14 | **0**（目視） |
| 🟡で目視確認した誤検知 | 「信条」(禁止事項)・サービス内容の予告なし変更 など | 修正済み |

残った🔴3件は、どれも「事業者自身の落ち度による損害を一切負わない」と書かれ、規約のどこにも故意・重過失の例外がないもの（消費者契約法8条1項1号の典型）。

## 修正内容
1. **文書全体の例外規定を考慮**（EXC-01）：別の条に「故意・重過失を除く」「消費者契約法の消費者契約に該当する場合は適用しない」があれば🟡に下げ、その条番号を表示。9本中5本がこの書き方だった。
2. **文脈による格下げ**（EXC-01・PAY-02）：第三者・利用者間・外部サービス・不可抗力・ユーザー自身の行為が原因の免責は🟡。
3. **COP-01**：主語がユーザー/投稿のときだけ検出（「当社サービスの著作権は当社に帰属」を除外）。
4. **PRV-02**：取得・提供の文脈を必須に（禁止事項の「信条」を除外）。
5. **SUS-01**：対象がアカウント・利用資格のときだけ検出。
6. **見出し「1. 定義」形式**の条項分割に対応。

回帰テストは `test/run.js` に追加済み（合成文のみ。実在規約の本文はリポジトリに入れない）。

## 運用ルール（辞書に追記する方針）
- 名詞を伴わない動詞句（例：「無償で譲渡する」単独）をパターンにしない
- 「🔴」は「その規約全体を読んでも例外がない」場合に限る
- 実在企業名を出すときは「条文の引用＋該当ルール」の事実のみ。「違法」とは書かない
