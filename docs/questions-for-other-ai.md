# サービス概要
- 名前：規約チェッカー（Web版・スマホ対応）
- 機能：利用規約の文章を貼ると、条項ごとに「🔴危険／🟡注意／🟢安全」に色分けし、根拠条文（消費者契約法8・9・10条、民法548条の2、個人情報保護法など）と一言解説を表示する
- 判定方法：公開している30項目のルール（正規表現）で判定。AIは使っていない。規約はサーバーに送らず、ブラウザ内だけで判定する
- 無料・登録不要。「法的助言ではありません」と全画面に表示
- 現状：v1が完成し、公開直前（GitHub Pagesで無料公開の予定）

# 目標と制約
- 90日以内に「登録」100名。登録＝「規約変更アラート（準備中の機能）」へのメール先行登録
- 予算：手持ち1万円（ドメイン代約1,500円以外は使わない予定）
- 運営は1人＋AI。広告費はほぼゼロ

# ここまでの検証結果
- 有名サービス9本（大手Webサービス。社名は伏せる）の規約で精度を検証
- 最初は「一切の責任を負いません」に反応して🔴が17件出たが、うち14件は誤りだった（9本中5本は、別の条で「故意・重過失の場合は除く」と例外を定めていた）
- 規約全体の例外規定まで見るよう改良し、🔴は3件まで減った（残りは例外規定のない全部免除）
