自動更新

お客様のHulu見放題サービスへの加入は、お客様がHulu見放題サービスの利用をキャンセルされるまで、又はアカウント若しくはサービスが本利用規約に従い停止若しくは中止されるまで、1か月毎に継続的に更新されます。HJホールディングス サービス利用規約（Hulu 見放題） 4. 加入及び料金請求 (4) 継続加入及びキャンセル

自分で解約するまで、毎月自動で更新されます。

解約の締め切り

翌月のHulu見放題サービスの料金請求を回避するためには、月次の更新がなされる前にHulu見放題サービスをキャンセルする必要があります。HJホールディングス サービス利用規約（Hulu 見放題） 4. 加入及び料金請求 (4) 継続加入及びキャンセル

翌月の料金を止めたいなら、更新日の前に解約します。

月の途中の解約

お客様が月中にHulu見放題サービスの利用をキャンセルした場合は、当該月の利用料は返金されませんが、当該月の残りの期間中は継続してHulu見放題サービスを利用することができます。HJホールディングス サービス利用規約（Hulu 見放題） 4. 加入及び料金請求 (4) 継続加入及びキャンセル

月の途中で解約しても、その月の料金は戻りません。そのかわり、その月の終わりまでは見られます。

返金

すべての料金及び手数料は、理由の如何を問わず、返金しません。HJホールディングス サービス利用規約（Hulu 見放題） 4. 加入及び料金請求 (2) 料金請求

規約上、払った料金や手数料は、どんな理由でも返金しないことになっています。

料金の変更

変更された場合には、当社は、これらの内容につき電子メールにて事前にお客様に通知いたします。HJホールディングス サービス利用規約（Hulu 見放題） 4. 加入及び料金請求 (2) 料金請求
