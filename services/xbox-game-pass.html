Xbox Game Passの解約・返金・自動更新
利用規約に書いてあること

出典：XBOX サブスクリプションとクラウドの利用規約（最終更新 2026年11月11日）。2026-11-15 に確認。

ポイント

  • キャンセルするまで、自動で継続・請求されます
  • 請求を止めるには、次の請求日までにキャンセルが必要です
  • 最初の購入日から30日以内なら、キャンセルで払い戻しを受けられます
  • 値上げは30日以上前に知らされます

自動更新

定期サブスクリプションはキャンセルされるまで自動的に継続され、その時点の定額料金 (変更されることがあります) および適用される税金が請求されますXBOX サブスクリプションとクラウドの利用規約 XBOX Game Pass の利用に関するお知らせ

キャンセルするまで自動で続き、そのときの料金が請求されます。

解約の締め切り

請求を停止するには、次の請求日までに、Microsoft アカウント ( account.microsoft.com/services ) または XBOX コンソールからサブスクリプションをキャンセルするか、定期請求をオフにしてください。XBOX サブスクリプションとクラウドの利用規約 定期請求

次の請求日までに、Microsoft アカウントか本体からキャンセル（または定期請求をオフ）します。

30日以内の払い戻し

払い戻しについてはサブスクリプションの取り消しによって初期購入日から30日以内にお受け取りになれますXBOX サブスクリプションとクラウドの利用規約 定期請求

最初に買った日から30日以内なら、キャンセルして払い戻しを受けられます（対象外と書かれた商品を除く）。

払い戻し後の特典

特定の月のサブスクリプションがキャンセルされ返金された場合、その月のコンテンツ配信はアカウントから削除される場合がありXBOX サブスクリプションとクラウドの利用規約 XBOX Game Pass Ultimate サブスクリプションの使用条件

払い戻しを受けると、その月にもらった特典（V-Bucks など）が消されることがあります。

料金の変更

Microsoft Store 販売条件に記載の通り、少なくとも 30 日前の通知をもって、料金を上げる場合があります。XBOX サブスクリプションとクラウドの利用規約 定期請求

値上げは30日以上前に知らされます。

他社経由の支払い

サード パーティがサブスクリプションの請求を行っている場合には、請求やキャンセル、返金の情報についてはそちらへお問い合わせください。XBOX サブスクリプションとクラウドの利用規約 定期請求

他社を通して払っている場合は、請求・キャンセル・返金はそちらに問い合わせます。
